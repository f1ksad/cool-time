# Console Timer on Python

Простой и удобный консольный таймер обратного отсчета с красивым отображением времени в формате MM:SS.

## Возможности:
* Готовые пресеты для повседневных дел (чистка зубов, варка яиц).
* Возможность задать своё время в секундах.
* Динамическое обновление времени в одной строке (без захламления консоли).

## Как запустить:
1. Скачайте файл `timer.py`.
2. Запустите в терминале: `python timer.py`
3. Или что бы запустить откройте папку `Russian edition` за тем зайдите в пупку `dist` и там откройте файл `time`
